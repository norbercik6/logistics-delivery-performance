# Project 1 — Logistics & Delivery Performance Dashboard

**Purpose:** Demonstrate KPI reporting and analysis of delivery performance using synthetic data.

## Business questions
- What is the on-time delivery rate?
- Which carrier has the highest delay frequency?
- How do transport costs vary across orders and carriers?
- Which late orders have high cost and therefore merit investigation?

## Tools
Excel, formulas, charts; optional Power BI and SQL.

## Data
300 simulated orders. All dates, carriers, costs, and delivery outcomes are fictional and created for portfolio practice. This is not Weber data.

## How to use
1. Open `01_Logistics_Delivery_Performance.xlsx`.
2. Review `Orders`, `KPI_Summary`, and `Carrier_Analysis`.
3. Refresh/recalculate formulas in Excel if needed.
4. Import `Orders` into Power BI to build a dashboard with cards for total orders, on-time rate, late orders and average delay; add carrier and region slicers.
5. Use `project1_queries.sql` for example SQL analysis.

## Suggested improvement actions
Treat these as hypotheses to test, not conclusions about a real operation:
- Review carrier performance with a standard weekly scorecard.
- Investigate expensive late orders and segment by distance and region.
- Agree on a consistent definition of on-time delivery and monitor the trend weekly.

## Portfolio disclosure
Training project using synthetic data; no real company data or operational results.
